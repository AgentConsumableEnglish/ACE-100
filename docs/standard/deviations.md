# The deviations ledger

Each row records one declared exemption (ACE 13.7, 17.7). Read the reason of a row before you correct its deviation. Each adopter keeps its own copy of this ledger.

| Document | Exempt from | Reason |
|---|---|---|
| `docs/standard/agent-brief.md` | ACE 15.1 | The brief exists so that a writer learns the whole standard from one document. A division causes the failure that ACE 15.5 names. |
| `docs/standard/agent-brief.md` | ACE 14.9 | The division line shows the example shape, a path with no file. The example is the point. |
| `docs/standard/architecture/size-limits.md` | ACE 14.9 | ACE 15.2 shows the division shape with example paths. An example path names no real file on purpose. |
