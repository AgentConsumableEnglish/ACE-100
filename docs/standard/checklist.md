# The checklist

Do these checks in the given sequence. Stop and correct the document at each failed check.

1. Words: make sure that each word is approved, declared, or backticked (ACE 1.1, 1.5).
2. Meanings: make sure that each word keeps its approved meaning and part of speech (ACE 1.2, 1.3).
3. Verbs: make sure that all verbs use simple tenses and the active voice (ACE 3.2, 3.6).
4. Modality: make sure that only `can`, `must`, and `will` occur (ACE 3.7).
5. Sentences: count the words against the applicable limit (ACE 5.1, 6.1).
6. Paragraphs: make sure that each paragraph has one topic and five sentences maximum (ACE 6.5, 6.6).
7. Terms: make sure that each noun cluster has three words maximum (ACE 2.1).
8. Safety: make sure that each risk has a warning or a caution (Section 7).
9. Notes: remove the notes, and make sure that the procedure stays complete (ACE 5.5).
10. Type: make sure that the document has one correct type and template form (ACE 12.1).
11. Front matter: check the mandatory properties and the H1 (ACE 13.2, 13.6).
12. Size: count the prose words and the lines against the limits (ACE 15.1, 15.2).
13. Links: make sure that each link points to a file and operates (ACE 14.5).
14. Index: make sure that the index of the directory lists the document (ACE 11.6).
15. Dictionary: add each new word in this PR, with its entry (ACE 1.11).
