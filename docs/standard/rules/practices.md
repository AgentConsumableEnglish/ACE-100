# Section 9 — Practices

**ACE 9.1** — When a word-for-word replacement is not sufficient, write the sentence again. Start from the meaning and from the action that the reader must do. Then make the sentence again with approved words. If it is necessary, divide the sentence or remove information that is not necessary. The test of success: each sentence is immediately clear on the first read.

**ACE 9.2** — Obey the restricted meaning of each approved word. Examples:

- "Above" and "below" are physical positions only. For limits, use "more than" and "less than".
- "See" refers to the eyes only. For references, use "refer to".

**ACE 9.3** — Be consistent. Use the same term for the same item in all documents. Use the same words for the same type of instruction.

## Recommendations

These prevent frequent errors. They are recommendations, not rules.

- **ACE R1** — Write "that" after verbs that report. ("Make sure that the test passes.")
- **ACE R2** — If a pronoun can refer to more than one noun, replace the pronoun with the noun.
- **ACE R3** — Make sure that "this" refers to one item only. If it does not, give the noun again.
- **ACE R4** — Give data, not general words. Replace "soon" or "several" with the number or the time.
- **ACE R5** — Use language that is applicable to all genders. Do not use "he", "she", "man", or "woman".
- **ACE R6** — The possessive ('s) is permitted. If you are not sure that it is correct, use "of".
- **ACE R7** — Read each sentence that has "with" again. Keep the primary action verb. ("Seal the port with a plug", not "Use a plug to seal the port".)
