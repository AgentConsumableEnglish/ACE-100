# Section 5 — Procedures

Procedural text tells the reader to do actions. The `HowTo` document type uses these rules. [Section 8](punctuation-and-counts.md) gives the word-count method.

**ACE 5.1 (M)** — Use a maximum of 15 words in each procedural sentence. This limit includes warnings and cautions. A note can have a maximum of 20 words.

**ACE 5.2** — Write one instruction in each sentence. Two actions in one sentence are permitted only when they occur at the same time. ("Hold the button and read the output.")

**ACE 5.3** — Write instructions in the imperative. ("Start the migration", not "The migration can be started".) Use "must" before an instruction only for a safety-critical condition.

**ACE 5.4** — Write the condition first, then the command. Put a comma between them. ("When the check is green, merge the PR.")

**ACE 5.5** — A note gives information only. Do not put instructions, limits, or results in a note. Do this test: remove all the notes, and make sure that the procedure is complete.

**ACE 5.6** — Give each step a number. Put one step in each list item. A step can have more than one sentence only when:

- The actions occur at the same time.
- A result or a limit comes immediately after an action.
