# Section 2 — Multi-word terms

**ACE 2.1** — Use a maximum of three words in a noun cluster. Divide a longer cluster with prepositions. ("Deployment pipeline configuration file validation" is not correct. Write "Validation of the configuration file for the deployment pipeline".)

**ACE 2.2** — For a long official term, write the full term the first time. Then use one of these:

- A shorter approved form or a declared abbreviation.
- Hyphens that connect the words that operate as one unit.

**ACE 2.3** — Obey these limits for hyphens in terms:

- Do not connect words that are not related.
- Do not make hyphenated groups of more than three units.
- Do not change the hyphens of an official name.

**ACE 2.4** — Do not use many abbreviations in one document. Declare each abbreviation in the dictionary before use.
