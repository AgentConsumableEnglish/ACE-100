# Section 1 — Words

**ACE 1.1 (M)** — The vocabulary is closed. Use only:

- Words that the [dictionary](../../dictionary/README.md) approves.
- Technical terms that [technical-terms.md](../../dictionary/technical-terms.md) declares.
- Quoted text and backticked identifiers.

**ACE 1.2** — Use an approved word only as the part of speech that the dictionary gives.

**ACE 1.3** — Use an approved word only with its approved meaning. ("Follow" means "come after". For instructions, use "obey".)

**ACE 1.4** — Plural forms of approved nouns are approved. The dictionary gives the approved verb forms.

**ACE 1.5 (M)** — Write each code identifier in backticks. This includes commands, flags, paths, filenames, values, and names from code. Backticked text is quoted text. The vocabulary rules do not apply to it.

**ACE 1.6** — A technical term is a name for a real thing in your domain. Examples of categories: products, services, teams, vendors, protocols, and standards. Declare each technical term in the dictionary before use, or in the same PR.

**ACE 1.7** — Do not use a noun as a verb. ("Version the schema" is not correct. Write "Give the schema a version".)

**ACE 1.8** — Use a maximum of three words in a new technical term.

**ACE 1.9** — Do not use slang, jargon, or regional words. ("Nuke the cache" is not correct. Write "Delete the cache".)

**ACE 1.10** — Use one name for each item in all documents. Do not change between names for the same item.

**ACE 1.11** — When a necessary word is missing, add it to the dictionary in the same PR. [Add a word](../../dictionary/add-a-word.md) gives the procedure.

**ACE 1.12** — Use American English spelling. Do not change the spelling of quoted text.
