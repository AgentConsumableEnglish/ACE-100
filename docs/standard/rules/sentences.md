# Section 4 — Sentences

**ACE 4.1** — Write short and clear sentences. Give one topic in each sentence. Be accurate. Do not write abstract statements. ("Errors are unacceptable" is not correct. Write "Make sure that the log shows zero errors".)

**ACE 4.2 (M)** — Keep all the necessary words. Keep the subjects, the verbs, and the articles. Do not use contractions. Write "do not", not "don't".

**ACE 4.3** — Use a vertical list to make complex text clear. Obey these rules:

- Put a colon before the list.
- Start each item with a capital letter.
- Put a period after an item that is a full sentence.
- Make sure that the grammar of each item agrees with the lead-in.
- Do not mix instructions and descriptions in one list.

**ACE 4.4** — Use connection words to connect sentences with related topics. Examples: "and", "but", "then", "thus", "as a result".

**ACE 4.5** — Use the articles and the demonstrative adjectives before nouns. There are two exceptions:

- General statements have no article. ("Secrets can cause damage in logs.")
- A noun with an identifier after it has no definite article. ("Stop container `web-1`.")

**ACE 4.6** — In a safety list, write the negative command again in each item.
