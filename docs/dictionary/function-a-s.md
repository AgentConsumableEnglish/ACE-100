# Function core A to S

The function layer is closed (ACE 1.1). Use only the words in these parts.

| Word | Part | Meaning |
|---|---|---|
| A | determiner | One item, not a specific one. |
| ABOUT | preposition | On the topic of. Also: near the given number. |
| ABOVE | preposition | In a higher physical position only. For limits, use MORE THAN. |
| ACROSS | preposition | From one side to the other side of. |
| AFTER | preposition | Later than. Also: in the position that comes next. |
| AGAIN | adverb | One more time. |
| AGAINST | preposition | In comparison with. Also: in contact with. |
| ALL | determiner | The full quantity of. |
| ALMOST | adverb | Near to, but not fully. |
| ALONE | adverb | With no other item. |
| ALONG | preposition | On a path that follows. |
| ALREADY | adverb | Before this time. |
| ALSO | adverb | In addition. |
| ALWAYS | adverb | At all times. |
| AN | determiner | One item, before a vowel sound. |
| AND | conjunction | Connects two items or two sentences. |
| ANOTHER | determiner | One more, or a different one. |
| ANY | determiner | One or more, with no restriction on which. |
| ANYTHING | pronoun | One thing of any kind. |
| AROUND | preposition | On a path that circles. Also: near. |
| AS | conjunction | In the function of. Also in: AS A RESULT, AT THE SAME TIME. |
| AT | preposition | In the exact location, time, or value of. |
