# Core A

[Conventions](conventions.md) gives the entry format and the principles.

| Word | Part | Meaning |
|---|---|---|
| A | determiner | One item, not a specific one. AN before a vowel sound. |
| ABBREVIATION | noun | A short form of a term. Declare it before use. |
| ABOUT | preposition | On the topic of. Also: near the given number. |
| ABOVE | preposition | In a higher physical position only. For limits, use MORE THAN. |
| ABSTRACT | adjective | Without specific data. Abstract statements are not permitted. |
| ACCEPT | verb | To agree to and record as approved. |
| ACCESS | noun | The ability to reach, read, or change an item. |
| ACCURATE | adjective | Correct in each detail. |
| ACRONYM | noun | An abbreviation that persons speak as a word. |
| ACTION | noun | One thing that a person, agent, or system does. |
| ACTIVE | adjective | In operation. Also: the voice where the subject does the action. |
| ADAPT | verb | To change an item so that it is correct for a new use. |
| ADD | verb | To put a new item into a group or a document. |
| ADDRESS | noun | The location of a system, service, or resource. |
| ADJECTIVE | noun | A word that describes a noun. |
| ADOPT | verb | To start to use an item as your own. |
| ADVERB | noun | A word that describes a verb or an adjective. |
| AFTER | preposition | Later than. Also: in the position that comes next. |
| AGAIN | adverb | One more time. |
| AGAINST | preposition | In comparison with. Also: in contact with. |
| AGENT | noun | A program that reads, decides, and does work. Also: the doer of an action. |
| AGREE | verb | To have the same position or form. |
| AGREEMENT | noun | The state where two items have the same position or form. |
| ALL | determiner | The full quantity of. |
| ALLOWLIST | noun | A list of permitted items. |
| ALONE | adverb | With no other item. |
| ALSO | adverb | In addition. |
| ALTERNATIVE | noun | A different permitted selection. |
| AMERICAN | adjective | Of the United States. For spelling (ACE 1.12). |
| AN | determiner | One item, before a vowel sound. |
| ANALYSIS | noun | An examination of the parts of a problem. |
| AND | conjunction | Connects two items or two sentences. |
| ANOTHER | determiner | One more, or a different one. |
| ANSWER | noun | The information that a question asks for. |
| ANSWER | verb | To give the information that a question asks for. |
| ANY | determiner | One or more, with no restriction on which. |
| APPLICABLE | adjective | Correct for this condition or context. |
| APPLY | verb | To put an item into use or onto a surface. Also: to be applicable. |
| APPROVAL | noun | A recorded agreement to a change. |
| APPROVE | verb | To give approval to. |
| ARCHITECTURE | noun | The structure of a system or of a document set. |
| ARTICLE | noun | One of the words THE, A, and AN. |
| AS | conjunction | In the function of. Also in: AS A RESULT, AT THE SAME TIME. |
| AT | preposition | In the exact location, time, or value of. |
| ATTACH | verb | To connect an item to another item. |
| AUDIENCE | noun | The group that reads a document. |
| AUTHOR | noun | The person or agent that writes a document. |
