# Replacements

Do not use the words in the left column. Use the approved alternatives. When a word-for-word replacement does not operate, write the sentence again (ACE 9.1).

## Deletions

These words add no meaning in governed prose. Delete the word. The sentence keeps its meaning without it.

| Not permitted |
|---|
| actually, basically, essentially, really |
| generally, just, simply, very |
