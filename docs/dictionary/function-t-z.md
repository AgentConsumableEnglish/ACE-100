# Function core T to Z

The function layer is closed (ACE 1.1). Use only the words in these parts.

| Word | Part | Meaning |
|---|---|---|
| TEN | number | 10. For larger numbers, use digits. |
| THAN | conjunction | In comparisons: MORE THAN, LESS THAN, RATHER THAN. |
| THAT | conjunction | Starts a report clause. Also a determiner: the given item. |
| THE | determiner | The specific item. |
| THEIR | determiner | Of the given items or persons. |
| THEM | pronoun | The given items or persons. |
| THEN | adverb | After that. |
| THERE | adverb | In that location. Also in: THERE IS, THERE ARE. |
| THESE | determiner | The given items, near. |
| THEY | pronoun | The given items or persons. |
| THIS | determiner | The given item, near. |
| THOSE | determiner | The given items, not near. |
| THREE | number | 3. |
| THROUGH | preposition | From one side to the other. Also: with the use of. |
| THUS | adverb | As a result. |
| TO | preposition | In the direction of. Also: the infinitive mark. |
| TOGETHER | adverb | As one group. |
| TOO | adverb | More than the limit. Also: in addition. |
| TWICE | adverb | Two times. |
| TWO | number | 2. Also in: THE TWO, for both. |
| UNDER | preposition | In a lower position than. Also: inside the tree of. |
| UNTIL | conjunction | Up to the time when. |
| UP | adverb | To a higher position only. |
| WE | pronoun | The organization that issues the document. |
| WHAT | pronoun | Asks for or points to a thing. |
| WHEN | conjunction | At the time that. |
| WHERE | adverb | In the location that. |
| WHICH | pronoun | Asks for or points to one of a set. |
| WHO | pronoun | Asks for or points to a person. |
| WHY | adverb | For what reason. |
| WILL | verb | The simple future only. |
| WITH | preposition | Together with. Also: with the use of. |
| WITHIN | preposition | Inside the limits of. |
| WITHOUT | preposition | With no. |
| WOULD | verb | Only for a condition that is not real: a rejected alternative, or a path not taken. |
| YES | adverb | The positive answer. |
| YOU | pronoun | The reader. |
| YOUR | determiner | Of the reader. |
| ZERO | number | 0. Also: the count of an empty set. |
