# Core B

[Conventions](conventions.md) gives the entry format and the principles.

| Word | Part | Meaning |
|---|---|---|

| BACKTICKED | adjective | Inside backticks. |
| BACKUP | noun | A copy of data that you keep for recovery. |
| BE | verb | The verb of state. Forms: is, are, was, were, been is not permitted. |
| BECAUSE | conjunction | Gives the cause. |
| BECOME | verb | To change into a state. |
| BEFORE | preposition | Earlier than. Also: in the position in front of. |
| BELOW | preposition | In a lower physical position only. For limits, use LESS THAN. |
| BETWEEN | preposition | In the space or range that two items limit. |
| BLANK | adjective | With no content. |
| BLOCK | noun | A connected group of lines in a document. |
| BLOCK | verb | To stop movement or progress. |
| BODY | noun | The text of a document after the front matter. |
| BRANCH | noun | A line of development in version control. |
| BREAK | verb | To make an item stop its correct operation. |
| BUILD | verb | To make software from source code. |
| BUT | conjunction | Connects two sentences with opposite directions. |
| BY | preposition | Through the action or method of. |
