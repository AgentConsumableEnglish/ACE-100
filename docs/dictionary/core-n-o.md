# Core N to O

[Conventions](conventions.md) gives the entry format and the principles.

| Word | Part | Meaning |
|---|---|---|
| NAME | noun | The word or words that identify an item. |
| NECESSARY | adjective | That the purpose demands. |
| NEGATIVE | adjective | With NOT or DO NOT. Also: less than zero. |
| NEVER | adverb | At no time. |
| NEW | adjective | That did not exist before. |
| NEXT | adjective | The one that comes after this one. |
| NO | determiner | Not one. |
| NODE | noun | One machine of a cluster. |
| NORMAL | adjective | In the usual form. |
| NOT | adverb | Makes a negative. |
| NOTE | noun | Text that gives information only, near a procedure. |
| NOUN | noun | A word for a thing, a person, or a concept. |
| NUMBER | noun | A count or a value in digits. |
| OBEY | verb | To do what a rule or an instruction tells. |
| OBLIGATION | noun | A state where a rule demands an action. |
| OCCUR | verb | To happen at a time. |
| OF | preposition | Shows possession or connection. |
| OFFICIAL | adjective | From the organization with authority over the item. |
| OLD | adjective | From an earlier time. |
| OMIT | verb | To not include. |
| ON | preposition | In contact with the top or surface of. |
| ONCE | adverb | One time. |
| ONE | number | 1. Also: a single item. |
| ONE-LINE | adjective | Of one line. |
| ONLY | adverb | And no other. |
| OPEN | verb | To make ready for reading or change. |
| OPERATE | verb | To work correctly, or to use a system. |
| OPERATIONAL | adjective | Of the work to run systems. |
| OPTIONAL | adjective | Permitted but not mandatory. |
| OR | conjunction | Connects alternatives. |
| ORGANIZATION | noun | A company, association, or public body. |

| OUR | determiner | Of the organization. |
| OUTAGE | noun | A time when a service does not operate. |
| OUTLINE | noun | The topic structure of a document. |

| OUTSIDE | preposition | Not inside. |
| OWN | adjective | Of the same party. |
| OWNER | noun | The party with control of an item. |
