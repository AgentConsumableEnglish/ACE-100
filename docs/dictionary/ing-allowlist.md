# The -ing allowlist

ACE 3.4 does not permit "-ing" forms. The words in this table are the exceptions. Each word is a noun or an adjective, never a verb form.

| Word | Part | Meaning |
|---|---|---|
| BINDING | noun | The connection of a document type to its rule section |
| CACHING | noun | The storage of data for fast access |
| CASING | noun | The use of uppercase or lowercase letters |
| COUNTING | noun | The application of the count method |
| DURING | preposition | Through the time of |
| EXISTING | adjective | Present before this change |
| HEADING | noun | A title line in a document |
| LOAD-BEARING | adjective | That another system references and depends on |
| LOGGING | noun | The record function of a system |
| MEANING | noun | The concept that a word points to |
| MISSING | adjective | Not present |
| MONITORING | noun | The observation of a system |
| NAMING | noun | The selection of names |
| RECURRING | adjective | That occurs again and again |
| REMAINING | adjective | Left after the others go |
| ROUTING | noun | The selection of paths for data or readers |
| SPELLING | noun | The letters of a word |
| STAGING | noun | The environment before production |
| TRACING | noun | The record of one request through systems |
| VERSIONING | noun | The control of versions |
| WARNING | noun | Safety text for permanent harm |
| WRITING | noun | The activity or product of an author |

Technical terms and backticked identifiers with "-ing" stay permitted (ACE 3.4).
