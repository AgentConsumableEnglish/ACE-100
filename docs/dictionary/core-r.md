# Core R

[Conventions](conventions.md) gives the entry format and the principles.

| Word | Part | Meaning |
|---|---|---|
| READ | verb | To take information from text. |
| READER | noun | The person or agent that reads. |
| REAL | adjective | That exists, not fictional. |
| REASON | noun | The cause of a decision. |
| RECEIVE | verb | To get from a sender. |
| RECOMMENDATION | noun | Guidance that is not a rule. |
| RECORD | noun | Stored data about one item or event. |
| RECORD | verb | To store data about. |
| RECOVER | verb | To bring back to a good state. |
| RECOVERABLE | adjective | Possible to recover. |
| REFER | verb | To point the reader to. |
| REFERENCE | noun | A pointer to a document, an item, or a source. |
| REFUSE | verb | To not accept. |
| REGIONAL | adjective | Of one geographic area. Regional words are not permitted. |
| RELATED | adjective | With a connection. |
| RELATIVE | adjective | Measured from a given location. |
| RELEASE | noun | One approved version that goes to an environment. |
| RELEASE | verb | To make a version available. |
| REMOVE | verb | To take an item out of its location. |
| REPAIR | verb | To bring a broken item back to correct operation. |
| REPEAT | verb | To do again. |
| REPLACE | verb | To put a new item in the position of an old item. |
| REPLACEMENT | noun | The approved alternative for a word that is not permitted. |
| REPORT | verb | To give information. For verbs like SHOW and TELL. |
| REPOSITORY | noun | The version-controlled file tree. |
| REST | noun | The part that stays. |
| RESTART | verb | To stop and then start again. |
| RESTRICTED | adjective | With limits on meaning or use. |
| RESULT | noun | What an action causes. |
| REVERT | verb | To return software to the last good version. |
| REVIEW | noun | An examination of a change by another party. |
| REVIEW | verb | To do a review. |
| REVIEWER | noun | The party that does a review. |
| REWRITE | verb | To write again in a new form. Past: rewrote. |
| RISK | noun | A possible harm and its probability. |
| ROLE | noun | A named set of permissions or duties. |
| ROOT | noun | The top of a tree or repository. |
| ROUTE | verb | To send a reader or data on a path. |
| ROW | noun | A horizontal line of cells in a table. |
| RULE | noun | A statement that governed text must obey. |
| RUN | verb | To start and operate a program or procedure. Past: ran. |
